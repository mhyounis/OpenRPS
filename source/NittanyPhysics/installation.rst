Installation
============

The installation and execution of NittanyPhysics very closely mirrors Lionbolt, including the ability to run NittanyPhysics as a program informed by an input file, or through a driver file, or as a library linked to your own program. In order to access any of these capabilities you should read :ref:`the Lionbolt installation page <installation_lionbolt>`, whose instructions are identical to NittanyPhysics if one just replaces Lionbolt with NittanyPhysics (including the submit script, which is identically structured).
