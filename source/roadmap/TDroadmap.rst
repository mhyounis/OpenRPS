Terpdose
========

.. attention:: This page is WIP.

.. For the most part Terpdose updates will be based on updates to Lionbolt and NittanyPhysics. However, independently, the following is planned:

.. 1. Current Density and Electrodynamics
.. --------------------------------------

..     A new post-processing feature. Charged particle transport contributes to nonzero current densities, and in principle electromagnetic fields. Some capabilities for these calculations in Terpdose is planned.

.. 2. Cleaner Interface with Data Generated via the Lionbolt API
.. -------------------------------------------------------------

..     At the moment, Terpdose has really been written with only the main Lionbolt program in mind. Once the API has more specialization for custom HDF5 output, Terpdose will be updated to interact with HDF5 files that have more customized structure than the main program's HDF5 output.
